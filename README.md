# My App Monorepo (v2.0)

Enterprise-grade TypeScript monorepo with Next.js, Fastify, and Better Auth.

## Tech Stack

- **Monorepo**: pnpm + Turborepo
- **Frontend**: Next.js 16 + React 19
- **Backend**: Fastify + tRPC
- **Database**: PostgreSQL + Drizzle ORM
- **Auth**: Better Auth
- **Jobs**: BullMQ + Redis
- **Secrets**: Infisical (External)
- **Infra**: Docker + Nginx
